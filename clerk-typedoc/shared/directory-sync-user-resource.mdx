A user the identity provider has provisioned into the directory. Carries the same identifying fields as
`PublicUserData`.

## Properties

| Property                                   | Type                        | Description                                                  |
| ------------------------------------------ | --------------------------- | ------------------------------------------------------------ |
| <a id="active"></a> `active`               | `boolean`                   | `false` if the identity provider has deprovisioned the user. |
| <a id="id"></a> `id`                       | `string`                    | The unique identifier of the resource.                       |
| <a id="identifier"></a> `identifier`       | <code>null \| string</code> | The user's primary email address.                            |
| <a id="provisionedat"></a> `provisionedAt` | <code>null \| Date</code>   | The date the user was provisioned into the directory.        |
