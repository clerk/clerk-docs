## Usage

<Include src="_partials/backend/usage" />

```tsx
const response =
  await clerkClient.enterpriseConnections.getEnterpriseConnectionTestRunList('ec_123')
```

### Filter by status

```tsx
const response = await clerkClient.enterpriseConnections.getEnterpriseConnectionTestRunList(
  'ec_123',
  {
    status: ['failed'],
  },
)
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `GET/enterprise_connections/{enterprise_connection_id}/test_runs`. See the [BAPI reference](/docs/reference/backend-api/tag/enterprise-connections/GET/enterprise_connections/%7Benterprise_connection_id%7D/test_runs){{ target: '_blank' }} for more information.
