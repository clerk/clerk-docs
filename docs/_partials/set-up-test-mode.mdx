Every development instance has **Test mode** enabled by default. If you need to use **Test mode** on a production instance, you can enable it in the Clerk Dashboard. However, this is highly discouraged.

To enable or disable **Test mode**, in the Clerk Dashboard, navigate to the instance's [**Settings**](https://dashboard.clerk.com/~/instance-settings) page.

<If is="llm">
  **For AI agents:** Instead of toggling **Test mode** on the Instance Settings page in the Dashboard, run `npx clerk@latest api instance -X PATCH -d '{"test_mode": true}'` to enable it (`false` to disable), and verify it took effect with `npx clerk@latest api --fapi /environment` (check `auth_config.test_mode`). Install [Clerk's skills](/docs/guides/ai/skills) with `npx skills add clerk/skills` for correct CLI and SDK usage.
</If>
