The `<RedirectToSignUp />` component will navigate to the sign up URL which has been configured in your application instance. The behavior will be just like a server-side (3xx) redirect, and will override the current location in the history stack.

## Example

<If sdk="nextjs">
  ```tsx {{ filename: 'app/page.tsx' }}
  import { Show, RedirectToSignUp, UserButton } from '@clerk/nextjs'

  export default function Page() {
    return (
      <>
        <Show when="signed-in">
          <UserButton />
        </Show>
        <Show when="signed-out">
          <RedirectToSignUp />
        </Show>
      </>
    )
  }
  ```
</If>

<If sdk="electron">

  ```tsx {{ filename: 'src/App.tsx' }}
  import { Show, RedirectToSignUp, UserButton } from '@clerk/electron/react'

  export default function Page() {
    return (

        </Show>

          <RedirectToSignUp />
        </Show>
      </>
    )
  }
  ```

  > [!NOTE]
  > In Electron, `<RedirectToSignUp />` navigates to `signUpUrl`, which defaults to the Account Portal, and the Account Portal can't return to an Electron window. Set `signUpUrl` on [`<ClerkProvider>`](/docs/reference/components/clerk-provider) to a renderer route that renders `<SignUp />`. If you use a client-side router, pass `routerPush` and `routerReplace` too.
</If>
