The result of merging one user into another.
Used for `user.merged` webhook events and the response of the merge user endpoint.

## Properties

| Property                                 | Type       | Description                                      |
| ---------------------------------------- | ---------- | ------------------------------------------------ |
| <a id="deleted_user"></a> `deleted_user` | `UserJSON` | The merged user as it was before it was deleted. |
| <a id="user"></a> `user`                 | `UserJSON` | The user that remains, as it is after the merge. |
