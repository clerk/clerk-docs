A challenge issued by Clerk that must be signed with the device's private key.

## Properties

| Property                                       | Type                        | Description                                                                                                               |
| ---------------------------------------------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| <a id="clientdata"></a> `clientData`           | `string`                    | The exact string that must be signed by the device's private key.                                                         |
| <a id="trusteddeviceid"></a> `trustedDeviceId` | <code>null \| string</code> | The ID of the trusted device the challenge was issued for. Only present on sign-in and session reverification challenges. |
