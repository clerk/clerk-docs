---
title: Sign-in security
description: Protect existing accounts with Device Trust, account lockout, and user enumeration protection.
---

Sign-in security helps protect existing accounts from password guessing, stolen passwords, and account discovery. In the Clerk Dashboard, navigate to [**Sign-in security**](https://dashboard.clerk.com/~/protect/sign-in-security) under **Protect** to manage these settings. All three are included on every plan.

| Setting | What it does | Default |
| - | - | - |
| [Lock accounts after failed sign-ins](/docs/guides/protect/user-lockout) | Locks an account after too many failed sign-in attempts. | On for new applications. |
| [Device Trust](/docs/guides/protect/device-trust) | Requires a second factor for password sign-ins from a new device when the user hasn't enabled MFA. | On for applications created after November 14, 2025. |
| [Prevent user enumeration](/docs/guides/protect/user-enumeration-protection) | Makes it harder to find out which email addresses and phone numbers have an account. | Bulk protection is always on. You can switch to Strict. |

For applications created before November 14, 2025, see [how to enable Device Trust](/docs/guides/protect/device-trust#enable-device-trust).
