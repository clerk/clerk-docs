Ensure the **Native API** is enabled for your production instance. Otherwise, requests from your production app fail with a `native_api_disabled` error.

1. At the top of the Clerk Dashboard, in the instance selection dropdown, ensure that your production instance is selected.
1. Navigate to the [**Native applications**](https://dashboard.clerk.com/~/native-applications) page and ensure the Native API is enabled.

> [!WARNING]
> Enabling the Native API opens a public request pathway that bypasses browser-based CAPTCHA challenges. Learn more about [how the Native API affects challenges](/docs/guides/protect/getting-started#native-api-considerations).
