| Code | Description |
| - | - |
| `invalid_token` | The link isn't valid. |
| `expired` | The link expired before anyone opened it. Links work for up to 60 seconds. |
| `already_used` | Someone already opened the link. Each link works once. |
| `source_session_invalid` | The app's session ended, or the user can no longer sign in, such as when they're banned or locked. |
| `impersonation_in_progress` | The browser is signed in to an [impersonation](/docs/guides/users/impersonation) session. It stays in that session. |
| `other_user_signed_in` | The browser is signed in only as a different user. It stays signed in as that user. |
| `cross_site_request` | The browser didn't treat the link as a direct navigation. On Android, this happens when the intent that opens the link doesn't name your app as the referrer. |
