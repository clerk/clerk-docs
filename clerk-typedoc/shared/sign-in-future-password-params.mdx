Parameters for submitting a password to sign-in.

| Name            | Type     | Description                                                                                                                                    |
| --------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `emailAddress?` | `never`  | -                                                                                                                                              |
| `identifier?`   | `never`  | -                                                                                                                                              |
| `password`      | `string` | The user's password. Only supported if [password](/docs/guides/configure/auth-strategies/sign-up-sign-in-options#password) is enabled.         |
| `phoneNumber?`  | `never`  | -                                                                                                                                              |
| `timezone?`     | `string` | The timezone to assign to the new sign-in attempt. If omitted, reuses the current sign-in's timezone, then defaults to the browser's timezone. |
