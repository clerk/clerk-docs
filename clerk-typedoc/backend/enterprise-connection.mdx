The Backend `EnterpriseConnection` object holds information about an enterprise connection (SAML or OAuth) for an instance or organization.

## Properties

| Property                                                                         | Type                                                                                                                                            | Description                                                                                                                                                                                                                                      |
| -------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| <a id="active"></a> `active`                                                     | `boolean`                                                                                                                                       | Whether the connection is active or not.                                                                                                                                                                                                         |
| <a id="alloworganizationaccountlinking"></a> `allowOrganizationAccountLinking`   | `boolean`                                                                                                                                       | Whether existing users who are members of the organization can link their account to their enterprise identity.                                                                                                                                  |
| <a id="allowsubdomains"></a> ~~`allowSubdomains`~~                               | <code>undefined \| boolean</code>                                                                                                               | Whether users with an email address subdomain are allowed to use this connection or not. **Deprecated.** The Backend API does not return this field at the top level, so it is always `undefined`. Use `samlConnection.allowSubdomains` instead. |
| <a id="authenticatable"></a> `authenticatable`                                   | `boolean`                                                                                                                                       | Whether the connection can be used for sign-in and sign-up.                                                                                                                                                                                      |
| <a id="createdat"></a> `createdAt`                                               | `number`                                                                                                                                        | The date when the connection was first created.                                                                                                                                                                                                  |
| <a id="customattributes"></a> `customAttributes`                                 | <code>undefined \| [EnterpriseConnectionCustomAttribute](/docs/reference/backend/types/backend-enterprise-connection-custom-attribute)[]</code> | The custom attribute mappings of the connection. Only returned when the custom attributes feature is enabled for the instance.                                                                                                                   |
| <a id="disableadditionalidentifications"></a> `disableAdditionalIdentifications` | `boolean`                                                                                                                                       | Whether additional identifications are disabled for this connection.                                                                                                                                                                             |
| <a id="disablejitprovisioning"></a> `disableJitProvisioning`                     | `boolean`                                                                                                                                       | Whether Just-in-Time (JIT) provisioning of users is disabled for the connection.                                                                                                                                                                 |
| <a id="domains"></a> `domains`                                                   | <code>string[]</code>                                                                                                                           | The domain of the enterprise. Sign-in flows using an email with this domain may use the connection.                                                                                                                                              |
| <a id="id"></a> `id`                                                             | `string`                                                                                                                                        | The unique identifier for the connection.                                                                                                                                                                                                        |
| <a id="logopublicurl"></a> `logoPublicUrl`                                       | <code>undefined \| string</code>                                                                                                                | The public URL of the provider logo, if available.                                                                                                                                                                                               |
| <a id="name"></a> `name`                                                         | `string`                                                                                                                                        | The name to use as a label for the connection.                                                                                                                                                                                                   |
| <a id="oauthconfig"></a> `oauthConfig`                                           | <code>null \| [EnterpriseConnectionOauthConfig](/docs/reference/backend/types/backend-enterprise-connection-oauth-config)</code>                | OAuth (OIDC) configuration when the enterprise connection uses OAuth.                                                                                                                                                                            |
| <a id="organizationid"></a> `organizationId`                                     | <code>null \| string</code>                                                                                                                     | The Organization ID if the connection is scoped to an organization.                                                                                                                                                                              |
| <a id="provider"></a> `provider`                                                 | `string`                                                                                                                                        | The identity provider (IdP) of the connection. For example, `'saml_custom'` or `'oidc_custom'`.                                                                                                                                                  |
| <a id="samlconnection"></a> `samlConnection`                                     | <code>null \| [EnterpriseConnectionSamlConnection](/docs/reference/backend/types/backend-enterprise-connection-saml-connection)</code>          | SAML connection details when the enterprise connection uses SAML.                                                                                                                                                                                |
| <a id="syncuserattributes"></a> `syncUserAttributes`                             | `boolean`                                                                                                                                       | Whether the connection syncs user attributes between the IdP and Clerk or not.                                                                                                                                                                   |
| <a id="updatedat"></a> `updatedAt`                                               | `number`                                                                                                                                        | The date when the connection was last updated.                                                                                                                                                                                                   |
