OAuth configuration included on a Backend API [EnterpriseConnection](/docs/reference/backend/types/backend-enterprise-connection) response.

## Properties

| Property                                   | Type                             | Description                                                                |
| ------------------------------------------ | -------------------------------- | -------------------------------------------------------------------------- |
| <a id="authurl"></a> `authUrl`             | <code>undefined \| string</code> | The OAuth authorization URL.                                               |
| <a id="clientid"></a> `clientId`           | <code>undefined \| string</code> | The OAuth client ID.                                                       |
| <a id="createdat"></a> `createdAt`         | `number`                         | The date when the configuration was first created.                         |
| <a id="discoveryurl"></a> `discoveryUrl`   | <code>undefined \| string</code> | The OpenID Connect discovery URL.                                          |
| <a id="id"></a> `id`                       | `string`                         | The unique identifier for the OAuth configuration.                         |
| <a id="logopublicurl"></a> `logoPublicUrl` | <code>undefined \| string</code> | The public URL of the OAuth provider logo, if available.                   |
| <a id="name"></a> `name`                   | `string`                         | The name to use as a label for the configuration.                          |
| <a id="providerkey"></a> `providerKey`     | `string`                         | The OAuth provider key of the configuration. For example, `'custom_oidc'`. |
| <a id="requirespkce"></a> `requiresPkce`   | `boolean`                        | Whether the OAuth configuration requires PKCE.                             |
| <a id="tokenurl"></a> `tokenUrl`           | <code>undefined \| string</code> | The OAuth token URL.                                                       |
| <a id="updatedat"></a> `updatedAt`         | `number`                         | The date when the configuration was last updated.                          |
| <a id="userinfourl"></a> `userInfoUrl`     | <code>undefined \| string</code> | The OAuth user info URL.                                                   |
