title: Admin Logs
description: Learn how to use Admin Logs, the audit log for your Clerk workspace covering instance configuration changes, Role and Permission edits, integration setup, and other operations initiated from the Dashboard, Backend API, or Platform API.
---

The [**Admin Logs**](https://dashboard.clerk.com/~/admin-logs) page of the Clerk Dashboard provides a detailed audit log of workspace admin actions — whether performed by a workspace member through the Dashboard, programmatically through the [Backend API](/docs/reference/backend-api){{ target: '_blank' }} using a Clerk [Secret Key](!secret-key), or through the [Platform API](/docs/reference/platform-api){{ target: '_blank' }}. Admin Logs track actions such as creating OAuth applications, updating instance settings, rotating secrets, and managing Roles and Permissions.

> [!NOTE]
> Changes to end-user resources — such as the user and organization events below — are recorded in Admin Logs when made from the Dashboard or through the Backend API, and also appear in [Application Logs](/docs/guides/dashboard/logs/application-logs) so the affected instance's timeline stays complete. Actions end users take themselves in your application are recorded in Application Logs only.

To learn how to filter entries, inspect event details, and understand retention, see the [Logs overview](/docs/guides/dashboard/logs/overview).
