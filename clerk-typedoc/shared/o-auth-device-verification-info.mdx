Information about an OAuth device authorization.

## Properties

| Property                                                       | Type                                                                          | Description                                                                           |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| <a id="clientid"></a> `clientId`                               | `string`                                                                      | The OAuth `client_id` that identifies the application requesting authorization.       |
| <a id="expiresat"></a> `expiresAt`                             | `number`                                                                      | The expiration time of the device authorization, as a Unix timestamp in milliseconds. |
| <a id="oauthapplicationlogourl"></a> `oauthApplicationLogoUrl` | <code>null \| string</code>                                                   | The URL of the OAuth application's logo image, or `null` if no logo is available.     |
| <a id="oauthapplicationname"></a> `oauthApplicationName`       | `string`                                                                      | The display name of the OAuth application requesting authorization.                   |
| <a id="scopes"></a> `scopes`                                   | <code>[OAuthConsentScope](/docs/reference/types/oauth-consent-scope)[]</code> | The scopes the OAuth application is requesting.                                       |
| <a id="status"></a> `status`                                   | <code>"pending" \| "approved" \| "denied" \| "consumed"</code>                | The current status of the device authorization.                                       |
