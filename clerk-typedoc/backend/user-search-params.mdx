| Name                 | Type                                                                       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `banned?`            | `boolean`                                                                  | Filters users that are banned (`true`) or not banned (`false`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `deprovisioned?`     | `boolean`                                                                  | Filters users that are deprovisioned (`true`) or not deprovisioned (`false`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `emailAddressQuery?` | `string`                                                                   | Filters users with emails that match the given query, via case-insensitive partial match. For example, `emailAddressQuery=ello` will match a user with the email `HELLO@example.com`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `endingBefore?`      | `string`                                                                   | The `cursor.endingBefore` of a previous page. Returns the page before that one. It cannot be combined with `startingAfter`. A page read backward can hold fewer users than `limit` even when more users exist.                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `limit?`             | `number`                                                                   | Maximum number of users returned per page. Must be an integer greater than zero and less than `501`. Defaults to `10`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `metadata?`          | <code>[UserSearchMetadataFilter](user-search-metadata-filter.mdx)[]</code> | Filters users that match every one of the given metadata filters. Accepts up to 10 filters.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `nameQuery?`         | `string`                                                                   | Filters users with names that match the given query, via case-insensitive partial match.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `phoneNumberQuery?`  | `string`                                                                   | Filters users with phone numbers that match the given query, via case-insensitive partial match. For example, `phoneNumberQuery=555` will match a user with the phone number `+1555xxxxxxx`.                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `provider?`          | `string`                                                                   | Filters users that have an external account with the specified provider, for example `oauth_google`. Must be used together with `providerUserId`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `providerUserId?`    | <code>string[]</code>                                                      | Filters users with the specified provider user IDs for the given `provider`. Must be used together with `provider`. Accepts up to 100 provider user IDs.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `remainingCount?`    | <code>100 \| 1000 \| 10000 \| "exact"</code>                               | Also counts the users from the start of this page onward, this page included. On the first page that is every user the request matches. A number counts up to that many: the response's cursor carries `remainingCountExact` when there are fewer users than the number, and otherwise `remainingCountAtLeast`, set to that number. `'exact'` counts them all, with no limit. It takes longer the more users match, and the request fails if the count does not finish in time. The count is computed separately from the page. Treat it as a close estimate: it can differ slightly from the number of users that paging through the results returns. |
| `startingAfter?`     | `string`                                                                   | The `cursor.startingAfter` of the previous page. Omit it for the first page, and keep every other parameter the same across pages.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `usernameQuery?`     | `string`                                                                   | Filters users with usernames that match the given query, via case-insensitive partial match. For example, `usernameQuery=CoolUser` will match a user with the username `SomeCoolUser`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
