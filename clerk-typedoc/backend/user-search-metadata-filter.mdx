A filter on user metadata. A user matches when the filter's `match` holds for the value at `key` in the metadata named by `scope`.

## Properties

| Property                      | Type                                           | Description                                                                                                                                                                                          |
| ----------------------------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <a id="key"></a> `key`        | `string`                                       | A dot-separated path into the metadata, for example `settings.theme`. Escape a literal dot in a key as `\.`.                                                                                         |
| <a id="match"></a> `match`    | <code>"exists" \| "equals"</code>              | `exists` matches users that hold the key, whether it holds a value or nested keys. `equals` matches the whole value, case-insensitively. If the key holds an array, `equals` matches any item in it. |
| <a id="negate"></a> `negate?` | `boolean`                                      | If `true`, `exists` matches users that do not hold the key, and `equals` matches users that hold the key with a different value.                                                                     |
| <a id="scope"></a> `scope`    | <code>"public" \| "private" \| "unsafe"</code> | The metadata to match against.                                                                                                                                                                       |
| <a id="value"></a> `value?`   | `string`                                       | The value to compare against. Required for `equals` and not allowed for `exists`.                                                                                                                    |
