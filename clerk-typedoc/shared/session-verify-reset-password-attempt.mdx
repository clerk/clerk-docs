## Properties

| Property                                                      | Type                                                                    | Description                                                                                                                               |
| ------------------------------------------------------------- | ----------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| <a id="code"></a> `code`                                      | `string`                                                                | The one-time code sent to the user's email address or phone number.                                                                       |
| <a id="password"></a> `password`                              | `string`                                                                | The new password, which replaces the current one. Unlike a sign-in's reset attempt, it's required: the code only counts together with it. |
| <a id="signoutofothersessions"></a> `signOutOfOtherSessions?` | `boolean`                                                               | Whether to sign the user out of their other sessions once the new password is set.                                                        |
| <a id="strategy"></a> `strategy`                              | <code>"reset_password_email_code" \| "reset_password_phone_code"</code> | The strategy type.                                                                                                                        |
