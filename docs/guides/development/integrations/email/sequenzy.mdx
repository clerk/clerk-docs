[Sequenzy](https://www.sequenzy.com) is an email marketing and lifecycle automation platform that sends marketing, automated and transactional emails from one place.

This tutorial demonstrates how to sync your Clerk users to Sequenzy using [webhooks](/docs/guides/development/webhooks/overview), so that every new Clerk user becomes a Sequenzy subscriber. You will also learn how to send an email sequence to new Clerk users.

<Steps>
  ## Get your webhook URL from Sequenzy

  1. In the Sequenzy dashboard, navigate to **Settings** → **Integrations**.
  1. Next to **Clerk**, select **Connect**. A modal will open.
  1. Copy the webhook URL shown in the modal and save it somewhere secure. It has the format `https://api.sequenzy.com/api/webhooks/clerk/<your-company-id>`. Keep this modal open.

  ## Create a webhook endpoint in the Clerk Dashboard

  You must create a new Clerk webhook endpoint so that Clerk can send user data to Sequenzy.

  1. In the Clerk Dashboard, navigate to the [**Webhooks**](https://dashboard.clerk.com/~/webhooks) page.
  1. Select **Add Endpoint**.
  1. In the **Endpoint URL** field, paste the webhook URL that you copied from Sequenzy.
  1. In the **Subscribe to events** section, select the `user.created`, `user.updated`, and `user.deleted` events.
  1. Select **Create**. You'll be redirected to your endpoint's settings page.
  1. On the endpoint's settings page, copy the **Signing Secret**. It starts with `whsec_`.

  ## Add your signing secret in Sequenzy

  Sequenzy uses the signing secret to [verify](/docs/guides/development/webhooks/syncing) that each webhook was sent by Clerk.

  1. Return to the Clerk connection modal in Sequenzy.
  1. Paste the **Signing Secret**.
  1. Select **Connect Clerk**.

  New Clerk users will now be added to Sequenzy as subscribers. Sequenzy syncs each user's primary email address, first name, last name, and Clerk user ID. When a user is updated in Clerk, their subscriber is updated, and when a user is deleted in Clerk, their subscriber is unsubscribed.

  ## Send an email sequence to new users

  When Sequenzy adds a subscriber from a `user.created` event, it triggers a `contact.subscribed` event. To send a welcome sequence to every new Clerk user, create a sequence in Sequenzy that starts on the `contact.subscribed` event.

  You can personalize emails with the synced attributes, such as `{{firstName}}`.
</Steps>

> [!NOTE]
> Only users created after you connect Clerk are synced. To add existing Clerk users to Sequenzy, import them with a CSV file or the [Sequenzy API](https://docs.sequenzy.com).

For more details, see the [Sequenzy Clerk integration docs](https://docs.sequenzy.com/integrations/clerk).
