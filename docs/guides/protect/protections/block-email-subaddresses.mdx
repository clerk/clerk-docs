> [!NOTE]
> This protection is included on every plan, and it's off by default.

Many email providers deliver mail sent to a subaddress, such as `user+1@example.com`, to the same inbox as `user@example.com`. Someone can use this to create many accounts from a single inbox. This protection blocks an email address when another address that differs only by its subaddress already has an account.

## What it blocks

When someone signs up with an email address, or adds one to an existing account, Clerk removes the subaddress and checks whether the resulting base address is already registered. If it is, the new address is blocked. For example, if `user@example.com` already has an account, `user+1@example.com` is blocked.

Email providers use different formats for subaddresses, so Clerk applies different rules depending on the provider:

| Provider | Domains | Subaddress separators | Additional matching |
| - | - | - | - |
| Gmail | `gmail.com`, `googlemail.com` | `+`, `=`, `#` | Dots in the local part are ignored. For example, if `jsmith@gmail.com` already has an account, `j.smith@gmail.com` will be blocked. |
| Yahoo Mail | Yahoo's own mail domains: `yahoo.com`, `ymail.com`, `rocketmail.com`, `y7mail.com`, and Yahoo's country domains such as `yahoo.co.uk`, `yahoo.fr`, `yahoo.co.jp`, and `yahoo.com.br`. Domains that merely begin with a `yahoo` label, such as `yahoo.dev` or a `yahoo.` subdomain on a hosting provider, are not treated as Yahoo. | `+`, `=`, `#`, `-` | — |
| All other providers | Any other domain | `+`, `=`, `#` | — |

The first sign-up for a base address is allowed, even if it uses a subaddress. Only later sign-ups that use another variation of the same base address are blocked.

Existing accounts aren't affected. Users who already have an account with a subaddress can keep signing in.

## What happens when an address is blocked

The user sees an error that the email address is already in use, and can't continue with that address.

## Settings

This protection has no settings.

## How it works with other protections

[Block disposable email addresses](/docs/guides/protect/protections/block-disposable-email-addresses) blocks throwaway inboxes. This protection blocks extra accounts from one real inbox. They cover different tricks, so you can turn on both.
