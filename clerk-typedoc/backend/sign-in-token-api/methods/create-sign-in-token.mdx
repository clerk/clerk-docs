Creates a new sign-in token for the given user. By default, sign-in tokens expire in 30 days, or in 10 minutes when `secondFactorVerification` is set. You can optionally specify a custom expiration time in seconds using the `expiresInSeconds` parameter.

Returns the created [`SignInToken`](/docs/reference/backend/types/backend-sign-in-token) object.

```typescript
function createSignInToken(params: CreateSignInTokensParams): Promise<SignInToken>
```

## `CreateSignInTokensParams`


| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="expiresinseconds"></a> `expiresInSeconds?` | `number` | The number of seconds until the sign-in token expires. By default, the duration is `2592000` (30 days), or `600` (10 minutes) when `secondFactorVerification` is set. |
| <a id="orgid"></a> `orgId?` | `string` | The ID of the organization to activate when the user signs in. Organizations must be enabled for the instance, and the user must be a member of the organization. |
| <a id="secondfactorverification"></a> `secondFactorVerification?` | <code>"fresh" \| "stale"</code> | Lets a user with a second factor enabled complete the sign-in without being prompted for it. With `fresh`, the second factor is treated as verified at sign-in. With `stale`, it is treated as unverified, so any reverification that requires a second factor prompts the user to complete one. Has no effect for users without a second factor enabled. |
| <a id="userid"></a> `userId` | `string` | The ID of the user to create the sign-in token for. |
