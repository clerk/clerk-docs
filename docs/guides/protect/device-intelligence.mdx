title: Device Intelligence
description: Device Intelligence runs background browser checks. Learn how Require Device Intelligence checks uses the result.
---

Device Intelligence is a set of background browser checks used by [Clerk Protect](/docs/guides/protect/overview). ClerkJS runs the checks, and Clerk verifies the result. They add no visible step during sign-up. To run them, your application must meet [Protect's requirements](/docs/guides/protect/setup#requirements).

## How Require Device Intelligence checks uses the result

Device Intelligence doesn't block or challenge sign-ups on its own. [Require Device Intelligence checks](/docs/guides/protect/system-protections/require-device-intelligence) is a separate protection. When enabled, it blocks a browser sign-up if Clerk has no verified Device Intelligence result when the sign-up is created.

## Enable or disable Device Intelligence

Clerk enables Device Intelligence automatically when a new application is created or when an existing application passes or bypasses the Protect requirements check in the Clerk Dashboard. Device Intelligence has no Dashboard setting.

To disable Device Intelligence, first disable **Require Device Intelligence checks**, then [contact support](/contact/support). Without Device Intelligence, that protection blocks every browser sign-up.
