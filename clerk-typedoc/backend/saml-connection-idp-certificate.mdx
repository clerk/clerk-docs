One of the Identity Provider (IdP) signing certificates a SAML connection trusts.

## Properties

| Property                               | Type                        | Description                                                                                 |
| -------------------------------------- | --------------------------- | ------------------------------------------------------------------------------------------- |
| <a id="certificate"></a> `certificate` | `string`                    | The X.509 certificate, as base64-encoded DER without PEM armor.                             |
| <a id="expiresat"></a> `expiresAt`     | <code>null \| number</code> | The Unix timestamp (milliseconds) when the certificate expires, or `null` if unknown.       |
| <a id="issuedat"></a> `issuedAt`       | <code>null \| number</code> | The Unix timestamp (milliseconds) when the certificate becomes valid, or `null` if unknown. |
