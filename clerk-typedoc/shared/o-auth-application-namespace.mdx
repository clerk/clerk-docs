Namespace exposed on `Clerk` for OAuth application / consent helpers.

## Properties

| Property                                                         | Type                                                                                                                                                                                                                              | Description                                                                                                                                                                                                                                      |
| ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| <a id="buildconsentactionurl"></a> `buildConsentActionUrl`       | <code>(params: \{ clientId: string; \}) => string</code>                                                                                                                                                                          | Returns the URL to use as the `action` attribute of the consent form. Includes `_clerk_session_id` and, in development, the dev browser JWT. Custom-flow developers building their own consent UI use this alongside the `useOAuthConsent` hook. |
| <a id="getconsentinfo"></a> `getConsentInfo`                     | <code>(params: GetOAuthConsentInfoParams) => Promise\<[OAuthConsentInfo](/docs/reference/types/oauth-consent-info)\></code>                                                                                                       | Loads consent metadata for the given OAuth client for the signed-in user.                                                                                                                                                                        |
| <a id="lookupdeviceverification"></a> `lookupDeviceVerification` | <code>(params: [LookupOAuthDeviceVerificationParams](/docs/reference/types/lookup-oauth-device-verification-params)) => Promise\<[OAuthDeviceVerificationInfo](/docs/reference/types/oauth-device-verification-info)\></code>     | Looks up an OAuth device authorization by its human-readable user code.                                                                                                                                                                          |
| <a id="submitdeviceverification"></a> `submitDeviceVerification` | <code>(params: [SubmitOAuthDeviceVerificationParams](/docs/reference/types/submit-oauth-device-verification-params)) => Promise\<[OAuthDeviceVerificationResult](/docs/reference/types/oauth-device-verification-result)\></code> | Approves or denies an OAuth device authorization for the signed-in user.                                                                                                                                                                         |
