If you work with an AI coding agent, the [`clerk-migrate` skill](/docs/guides/ai/skills) can run your migration for you with the Clerk CLI. Install Clerk's skills:

```sh {{ filename: 'terminal' }}
npx skills add clerk/skills
```

Then ask your agent to migrate your users to Clerk. The skill exports your users, runs a dry run against your instance, and shows you what it found. It imports only after you approve.
