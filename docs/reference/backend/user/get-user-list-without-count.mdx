### Basic

```tsx
const { data } = await clerkClient.users.getUserListWithoutCount()
```

### Page through users

Gets users who match the query `test`, 100 at a time. Pagination uses `startingAfter`, which works only with `created_at` ordering (the default). See [Retrieve every user](/docs/reference/backend/user/get-user-list#retrieve-every-user).

```tsx
const limit = 100
let startingAfter: string | undefined

while (true) {
  const { data } = await clerkClient.users.getUserListWithoutCount({
    query: 'test',
    limit,
    startingAfter,
  })

  for (const user of data) {
    // Replace this with your own logic.
    console.log(user.id)
  }

  if (data.length < limit) break
  startingAfter = data[data.length - 1].id
}
```

To page in any order, or to filter by metadata, use [`searchUsers()`](/docs/reference/backend/user/search-users).

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `GET/users`. See the [BAPI reference](/docs/reference/backend-api/tag/users/GET/users){{ target: '_blank' }} for more information.
