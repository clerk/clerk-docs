Preview the users the import created, using the import run's ID:

```sh {{ filename: 'terminal' }}
clerk migrate undo <import_run_id> --dry-run
```

Then delete them:

```sh {{ filename: 'terminal' }}
clerk migrate undo <import_run_id> --yes
```

`--yes` doesn't delete users who have signed in since the import. Add `--include-signed-in` to authorize those deletions too. Confirming at the interactive prompt also authorizes them.

Pass the same `--instance`, `--app`, or `--secret-key` you gave the import. See [undo an import](/docs/guides/development/migrating/how-the-cli-migrates-users#undo-an-import) for confirmation rules, refusal conditions, and retries.
