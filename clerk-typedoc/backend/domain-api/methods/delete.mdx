Deletes a domain for the instance. The active domain cannot be deleted.

Returns the [`DeletedObject`](/docs/reference/backend/types/deleted-object).

```typescript
function delete(domainId: string): Promise<DeletedObject>
```

## Parameters


| Parameter | Type | Description |
| ------ | ------ | ------ |
| `domainId` | `string` | The ID of the domain to delete. |
