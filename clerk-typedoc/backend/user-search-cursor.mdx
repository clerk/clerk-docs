The position of a page of users returned by `searchUsers()`.

## Properties

| Property                                                    | Type                        | Description                                                                                                                                              |
| ----------------------------------------------------------- | --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <a id="endingbefore"></a> `endingBefore`                    | <code>string \| null</code> | The value to pass as `endingBefore` to get the page before this one. It is also set on pages read forward, and is `null` if there is no earlier page.    |
| <a id="hasnextpage"></a> `hasNextPage`                      | `boolean`                   | Whether there are more users after this page.                                                                                                            |
| <a id="remainingcountatleast"></a> `remainingCountAtLeast?` | `number`                    | A lower bound on the number of users from the start of this page onward. Present when `remainingCount` was a number and at least that many users remain. |
| <a id="remainingcountexact"></a> `remainingCountExact?`     | `number`                    | The number of users from the start of this page onward. Present when `remainingCount` was passed and the count did not reach its limit.                  |
| <a id="startingafter"></a> `startingAfter`                  | <code>string \| null</code> | The value to pass as `startingAfter` to get the next page, or `null` if this is the last page.                                                           |
