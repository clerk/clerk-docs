Call `Clerk.configure(publishableKey:options:)` once at app launch before accessing `Clerk.shared` or `@Environment(Clerk.self)`.

## Basic configuration

```swift
import ClerkKit
import SwiftUI

@main
struct MyApp: App {
  init() {
    Clerk.configure(publishableKey: "{{pub_key}}")
  }

  var body: some Scene {
    WindowGroup {
      ContentView()
        .environment(Clerk.shared)
    }
  }
}
```

## Configuration options

Use `Clerk.Options` to customize logging, telemetry, redirects, and more.

```swift
let options = Clerk.Options(
  logLevel: .debug,
  telemetryEnabled: true,
  keychainConfig: .init(
    service: "com.example.shared-auth",
    accessGroup: "ABCDE12345.com.example.shared-auth"
  ),
  proxyUrl: "https://proxy.example.com/__clerk",
  redirectConfig: .init(
    redirectUrl: "myapp://callback",
    callbackUrlScheme: "myapp"
  ),
  watchConnectivityEnabled: true,
  sharedSessionSync: .enabled,
  loggerHandler: { logEntry in
    print("[Clerk] \(logEntry.message)")
  },
  middleware: .init(
    request: [
      CustomHeaderMiddleware()
    ],
    response: [
      ResponseDiagnosticsMiddleware()
    ]
  )
)

Clerk.configure(publishableKey: "{{pub_key}}", options: options)
```

### `Clerk.Options`

<Properties>
  - `keychainConfig`
  - [`Clerk.Options.KeychainConfig`](#keychainconfig)

  Controls Keychain storage behavior.

  ---

  - `loggerHandler`
  - `(@Sendable (LogEntry) -> Void)?`

  Callback for error-level SDK logs.

  ---

  - `logLevel`
  - `LogLevel`

  Minimum SDK log level. Defaults to `.error`.

  ---

  - `middleware`
  - [`Clerk.Options.MiddlewareConfig`](#middlewareconfig)

  Configuration for request/response middleware.

  ---

  - `proxyUrl`
  - `URL?`

  Proxy URL for apps behind a reverse proxy, e.g., `https://proxy.example.com/__clerk`.

  ---

  - `redirectConfig`
  - [`Clerk.Options.RedirectConfig`](#redirectconfig)

  OAuth redirect URLs and callback handling.

  ---

  - `sharedSessionSync`
  - [`Clerk.Options.SharedSessionSyncConfig?`](#sharedsessionsyncconfig)

  Enables shared session sync between sibling apps on the same Apple Developer Team that share the same Keychain service and access group. All participating apps must also use the same Clerk [Publishable Key](!publishable-key). Defaults to `nil`. See [Share sessions across apps](/docs/reference/native-mobile/shared-session-sync).

  ---

  - `telemetryEnabled`
  - `Bool`

  Enables development telemetry collection. Defaults to `true`.

  ---

  - `watchConnectivityEnabled`
  - `Bool`

  Sync auth state to a watchOS companion app. Defaults to `false`.
</Properties>

### `KeychainConfig`

<Properties>
  - `accessGroup`
  - `String?`

  Access group for Keychain item sharing.

  ---

  - `service`
  - `String`

  Keychain service name. Defaults to the app bundle identifier.
</Properties>

### `RedirectConfig`

<Properties>
  - `callbackUrlScheme`
  - `String`

  Callback URL scheme. Defaults to the app bundle identifier.

  ---

  - `redirectUrl`
  - `String`

  OAuth redirect URL. Defaults to `{bundleIdentifier}://callback`.
</Properties>

### `SharedSessionSyncConfig`

<Properties>
  - `.enabled`
  - `Clerk.Options.SharedSessionSyncConfig`

  Turns on shared session sync between sibling apps. Requires a Keychain service and access group. See [Share sessions across apps](/docs/reference/native-mobile/shared-session-sync).
</Properties>

### `MiddlewareConfig`

<Properties>
  - `request`
  - `[ClerkRequestMiddleware]`

  Final-step request middleware for custom headers or diagnostics.

  ---

  - `response`
  - `[ClerkResponseMiddleware]`

  Response middleware that runs immediately after a response is received. Custom response middleware runs before Clerk's built-in response middleware.
</Properties>
