title: '`<InviteMembersButton />`'
description: Clerk's <InviteMembersButton /> component is used to render a button that opens a modal for inviting new members to an Organization.
sdk: nextjs, react, react-router, tanstack-react-start
---

The `<InviteMembersButton />` component renders a button that opens a modal containing the Organization invite-members form. It works like [`<SignInButton mode="modal">`](/docs/reference/components/unstyled/sign-in-button): wrap your own button and selecting it opens the modal.

> [!IMPORTANT]
> `<InviteMembersButton />` only works when there's an [Active Organization](!active-organization) and the current member has permission to manage memberships (`org:sys_memberships:manage`). Render it only for those members, gating it with [`<Show>`](/docs/reference/components/control/show) when you're unsure. If either requirement isn't met, selecting the button does nothing in production and throws a descriptive error in development.

## Usage

### Basic usage

By default, `<InviteMembersButton />` renders a button labeled "Invite members". The examples below gate it behind [`<Show>`](/docs/reference/components/control/show) to check whether the current member has the `org:sys_memberships:manage` permission before rendering it.

<If sdk="nextjs">
  ```tsx {{ filename: 'app/members/page.tsx' }}
  'use client'

  import { InviteMembersButton, Show } from '@clerk/nextjs'

  export default function MembersPage() {
    return (
      <Show when={{ permission: 'org:sys_memberships:manage' }}>
        <InviteMembersButton />
      </Show>
    )
  }
  ```
</If>

<If sdk="react">
  ```tsx {{ filename: 'src/components/Members.tsx' }}
  import { InviteMembersButton, Show } from '@clerk/react'

  const Members = () => {
    return (
      <Show when={{ permission: 'org:sys_memberships:manage' }}>
        <InviteMembersButton />
      </Show>
    )
  }

  export default Members
  ```
</If>

<If sdk="react-router">

### Custom usage

You can create a custom button by wrapping your own button, or button text, in the `<InviteMembersButton>` component. Any click handlers attached to your button are preserved.

<If sdk="nextjs">
  ```tsx {{ filename: 'app/members/page.tsx' }}
  'use client'

  import { InviteMembersButton, Show } from '@clerk/nextjs'

  export default function MembersPage() {
    return (
      <Show when={{ permission: 'org:sys_memberships:manage' }}>
        <InviteMembersButton>
          <button onClick={() => console.log('Opening invite modal')} className="custom-button">
            Invite members
          </button>
        </InviteMembersButton>
      </Show>
    )
  }
  ```
</If>

<If sdk="react">
  ```tsx {{ filename: 'src/components/Members.tsx' }}
  import { InviteMembersButton, Show } from '@clerk/react'

  const Members = () => {

            Invite members
          </button>
        </InviteMembersButton>

  ```
</If>

If you want to render multiple elements, wrap them in a single parent element:

```tsx
<InviteMembersButton>
  <button>
    <span>Invite</span>
    <span aria-hidden="true"> →</span>
  </button>
</InviteMembersButton>
```

## Properties

The `<InviteMembersButton />` component accepts the following properties, all of which are **optional**:

<Properties>
  - `children?`
  - `React.ReactNode`

  The button element to wrap. Only accepts one child; if you want to render multiple elements, wrap them in a single parent element. If not provided, defaults to a button with the text "Invite members".

  ---

  - `appearance?`
  - <code>[Appearance](/docs/guides/customizing-clerk/appearance-prop/overview) | undefined</code>

  An object to style your components. Will only affect [Clerk components](/docs/reference/components/overview) and not [Account Portal](/docs/guides/account-portal/overview) pages.
</Properties>
