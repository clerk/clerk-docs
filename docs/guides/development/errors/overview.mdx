---
title: Errors overview
description: Find more information about a Clerk error.
---

Clerk uses a set of error codes to communicate the status of an operation.

An error's type isn't always enough to understand what went wrong. In these cases, Clerk provides a more detailed error message called a long message that can help you better understand the issue.

To find the error that you're looking for, select the appropriate category in the sidenav. There are three categories of errors:

- [Backend API errors](/docs/guides/development/errors/backend-api): returned when your server calls Clerk, including through Clerk's backend SDKs.
- [Frontend API errors](/docs/guides/development/errors/frontend-api): returned to browser and native clients, including requests that Clerk's frontend SDKs and components make for you.
- [Platform API errors](/docs/guides/development/errors/platform-api): returned when you manage workspace resources, like applications and domains, through the Platform API.
