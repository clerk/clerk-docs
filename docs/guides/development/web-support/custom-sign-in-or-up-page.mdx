This guide shows you how to use the [`<SignIn />`](/docs/reference/components/authentication/sign-in) prebuilt component in order to build custom page that **allows users to sign in or sign up within a single flow**.

To set up separate sign-in and sign-up pages, follow this guide, and then follow the [custom sign-up page guide](/docs/guides/development/web-support/custom-sign-up-page).

This guide uses [Expo Router](https://docs.expo.dev/router/introduction/) and [platform-specific extensions](https://docs.expo.dev/router/advanced/platform-specific-modules/) to build a sign-in-or-up page for the web. Expo Router requires a non-platform route alongside a platform-specific route, so create both files shown below.

<Steps>
  ## Build a sign-in-or-up page

  Create both files in the following structure:

  ```text
  src/
  └── app/
      ├── sign-in.tsx
      └── sign-in.web.tsx
  ```

  The non-platform file renders the native [`<AuthView />`](/docs/reference/expo/native-components/auth-view). Because `<AuthView />` doesn't navigate on its own, the example watches the session and redirects once authentication completes. The `.web.tsx` file renders the web [`<SignIn />`](/docs/reference/components/authentication/sign-in) component, which allows users to sign in or sign up from a single flow.

  ```tsx {{ filename: 'src/app/sign-in.tsx' }}
  import { AuthView } from '@clerk/expo/native'
  import { useSession } from '@clerk/expo'
  import { useRouter } from 'expo-router'
  import { useEffect } from 'react'

  export default function Page() {
    const { session } = useSession()
    const router = useRouter()

    useEffect(() => {
      if (session?.status === 'active') {
        router.replace('/')
      }
    }, [session?.status, router])

    return <AuthView isDismissible={false} />
  }
  ```

  ```tsx {{ filename: 'src/app/sign-in.web.tsx' }}
  import { SignIn } from '@clerk/expo/web'

  export default function Page() {
    return <SignIn />
  }
  ```

  ## Visit your new page

  To run your project, use the following command:

  ```npm
  npm run web
  ```

  Visit your new custom pages locally at [localhost:8081/sign-in](http://localhost:8081/sign-in).
</Steps>
