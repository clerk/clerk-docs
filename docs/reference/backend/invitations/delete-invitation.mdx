## Usage

<Include src="_partials/backend/usage" />

```tsx
const invitationId = 'inv_123'

const response = await clerkClient.invitations.deleteInvitation(invitationId)
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `DELETE/invitations/{invitation_id}`. See the [BAPI reference](/docs/reference/backend-api/tag/invitations/DELETE/invitations/%7Binvitation_id%7D){{ target: '_blank' }} for more information.
