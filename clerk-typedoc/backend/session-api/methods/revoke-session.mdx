Revokes the given session. The user will be signed out from the client the session is associated with.

Returns the revoked [`Session`](/docs/reference/backend/types/backend-session).

```typescript
function revokeSession(sessionId: string, params: { resetDeviceTrust?: boolean }): Promise<Session>
```

## Parameters


| Parameter | Type | Description |
| ------ | ------ | ------ |
| `sessionId` | `string` | The ID of the session to revoke. |
| `params` | <code>\{ resetDeviceTrust?: boolean; \}</code> | The parameters to revoke the session with. |
| `params.resetDeviceTrust?` | `boolean` | When set to `true`, Clerk also forgets the device the session was signed in on, even if the session is already revoked. For a session that a native application received through hosted auth, Clerk also forgets the browser the user signed in on. The user's next sign-in on a forgotten device counts as a new device. That sign-in can require a Device Trust challenge, and Clerk can email the user about the new device. Other users on the same device are unaffected. Defaults to `false`. |
