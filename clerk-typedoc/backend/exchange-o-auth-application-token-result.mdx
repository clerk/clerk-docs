The result of a successful [OAuth 2.0 Token Exchange](https://www.rfc-editor.org/rfc/rfc8693#section-2.2.1).

## Properties

| Property                                       | Type                                                           | Description                                                                                                                                                                                                                                                                                                                                   |
| ---------------------------------------------- | -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <a id="accesstoken"></a> `accessToken`         | `string`                                                       | The issued security token.                                                                                                                                                                                                                                                                                                                    |
| <a id="expiresin"></a> `expiresIn?`            | `number`                                                       | The lifetime of the issued token in seconds, if provided by the authorization server.                                                                                                                                                                                                                                                         |
| <a id="issuedtokentype"></a> `issuedTokenType` | [`OAuthTokenTypeIdentifier`](o-auth-token-type-identifier.mdx) | The type of the issued token.                                                                                                                                                                                                                                                                                                                 |
| <a id="refreshtoken"></a> `refreshToken?`      | `string`                                                       | A refresh token, if issued by the authorization server.                                                                                                                                                                                                                                                                                       |
| <a id="scope"></a> `scope?`                    | <code>string[]</code>                                          | The scopes of the issued token, if provided by the authorization server.                                                                                                                                                                                                                                                                      |
| <a id="tokentype"></a> `tokenType`             | `string`                                                       | How the issued token is used, for example `Bearer`, as returned by the authorization server. Compare it case-insensitively ([RFC 6749 section 5.1](https://www.rfc-editor.org/rfc/rfc6749#section-5.1)), and only use the token if your code supports this type ([RFC 6749 section 7.1](https://www.rfc-editor.org/rfc/rfc6749#section-7.1)). |
