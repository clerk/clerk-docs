When the app's session ends, Clerk also ends the web sessions that its links created. This happens when the user signs out of your app or when you revoke the app's session.

Some web sessions stay signed in:

- If the browser was already signed in as the same user, the link may keep that existing session. Ending the app's session doesn't end it.
- When a new sign-in replaces the app's session, such as in single-session mode or with [hosted authentication](/docs/guides/account-portal/hosted-auth), Clerk doesn't end the web sessions. They still expire when the app's session would have.
