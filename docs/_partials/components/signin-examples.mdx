<If sdk="expo">
  <Include src="_partials/expo/web-only-callout" />

  Expo Router requires a non-platform route alongside `src/app/sign-in.web.tsx`, so this example also includes `src/app/sign-in.tsx`, which renders the native [`<AuthView />`](/docs/reference/expo/native-components/auth-view) component on iOS and Android.

  ```tsx {{ filename: 'src/app/sign-in.tsx' }}
  import { AuthView } from '@clerk/expo/native'

  export default function Page() {
    return <AuthView isDismissible={false} />
  }
  ```

  ```tsx {{ filename: 'src/app/sign-in.web.tsx' }}
  import { SignIn } from '@clerk/expo/web'

  export default function Page() {
    return <SignIn />
  }
  ```

  For a complete walkthrough, including redirecting native users once authentication completes, see the [custom sign-in-or-up page guide](/docs/guides/development/web-support/custom-sign-in-or-up-page).
</If>
