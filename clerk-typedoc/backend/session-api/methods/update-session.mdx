Changes when the given session expires. The new expiry applies to this session only and can exceed the instance's session lifetime. Only active and pending sessions can be updated.

Take the session ID from the `sid` claim of a verified session token, never from an unverified client request.

Returns the updated [`Session`](/docs/reference/backend/types/backend-session).

```typescript
function updateSession(sessionId: string, params: UpdateSessionParams): Promise<Session>
```

## Parameters


| Parameter | Type | Description |
| ------ | ------ | ------ |
| `sessionId` | `string` | The ID of the session to update. |
| `params` | [`UpdateSessionParams`](../update-session-params.mdx) | The parameters to update the session with. |
