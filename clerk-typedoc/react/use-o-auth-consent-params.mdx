## Parameters

| Parameter                  | Type                                                               | Description                                                                                                      |
| -------------------------- | ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| `params`                   | [`UseOAuthConsentParams`](../shared/use-o-auth-consent-params.mdx) | -                                                                                                                |
| `params.enabled?`          | `boolean`                                                          | If `true`, a request will be triggered when the hook is mounted and the user is signed in. Defaults to `true`.   |
| `params.keepPreviousData?` | `boolean`                                                          | If `true`, the previous data will be kept in the cache until new data is fetched. Defaults to `true`.            |
| `params.oauthClientId`     | `string`                                                           | The OAuth `client_id` from the authorize request. The hook is disabled when this value is empty or omitted.      |
| `params.redirectUri?`      | `string`                                                           | The redirect URI from the authorize request. When provided, the backend returns a PSL-resolved `redirectDomain`. |
| `params.scope?`            | `string`                                                           | A space-delimited scope string from the authorize request.                                                       |
