Merges the `fromUserId` user into the given user: moves its identifications, connected accounts, second factors, organization memberships, and metadata onto the given user, then deletes the `fromUserId` user. Where both users have a value, the given user keeps its own.

A merge cannot be undone. Use `dryRun` to preview one.

Returns the remaining [`User`](/docs/reference/backend/types/backend-user) after the merge, and the deleted user as it was before the merge.

```typescript
function mergeUser(userId: string, params: MergeUserParams): Promise<UserMergeResult>
```

## Parameters


| Parameter | Type | Description |
| ------ | ------ | ------ |
| `userId` | `string` | The ID of the user that remains after the merge. |
| `params` | [`MergeUserParams`](../merge-user-params.mdx) | The parameters for the merge. |
