The parameters for performing an [OAuth 2.0 Token Exchange](https://www.rfc-editor.org/rfc/rfc8693) for an OAuth application.

## Properties

| Property                                     | Type                  | Description                                                                                                                                                                                                           |
| -------------------------------------------- | --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <a id="clientid"></a> `clientId`             | `string`              | The client ID of the OAuth application performing the exchange.                                                                                                                                                       |
| <a id="clientsecret"></a> `clientSecret`     | `string`              | The client secret of the OAuth application, used to authenticate with the token endpoint.                                                                                                                             |
| <a id="proxyurl"></a> `proxyUrl?`            | `string`              | The absolute HTTPS URL of your Frontend API proxy. When set, the exchange is sent through the proxy instead of the Frontend API host in `publishableKey`.                                                             |
| <a id="publishablekey"></a> `publishableKey` | `string`              | The publishable key of the instance, used to derive its token endpoint.                                                                                                                                               |
| <a id="resource"></a> `resource`             | `string`              | The absolute URI of the target resource where the issued token will be used. It must use `https`, or `http` on `localhost`, `127.0.0.1` or `[::1]`, and must not contain a fragment. It is sent exactly as given.     |
| <a id="scope"></a> `scope?`                  | <code>string[]</code> | The scopes requested for the issued token. Each element must be a single, non-empty [scope token](https://www.rfc-editor.org/rfc/rfc6749#section-3.3): printable ASCII without spaces, double quotes, or backslashes. |
| <a id="subjecttoken"></a> `subjectToken`     | `string`              | The OAuth access token that represents the user on whose behalf the request is being made.                                                                                                                            |
