> [!IMPORTANT]
> Clerk supports both [Client ID Metadata Documents (CIMD)](/docs/guides/configure/auth-strategies/oauth/client-id-metadata-documents) and [Dynamic Client Registration](https://openid.net/specs/openid-connect-registration-1_0.html) for OAuth client registration. A CIMD-compatible client uses an HTTPS metadata URL as its client ID and doesn't need Dynamic Client Registration. CIMD is currently in beta — [contact support](/contact/support) to have it enabled for your account.
>
> In the Clerk Dashboard, navigate to the [**OAuth applications**](https://dashboard.clerk.com/~/oauth-applications) page and open the **CIMD Clients** tab. Enable **Advertise CIMD support** and **Only allow pre-registered clients to connect** together, then explicitly allow the client. Leave **Only allow pre-registered clients to connect** off only if your application should accept clients that haven't been reviewed in advance. Enable **Dynamic client registration** only if the client doesn't support CIMD and requires DCR.
