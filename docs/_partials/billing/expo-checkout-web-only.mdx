> [!IMPORTANT]
> Clerk Billing checkout is supported in Expo web apps only. Native iOS and Android apps can use the Billing object's data APIs to access Plans, Subscriptions, statements, and payment attempts, and use [`has()`](/docs/guides/secure/authorization-checks) to check Plan or Feature access. Clerk doesn't provide a native checkout surface or integrate with Apple In-App Purchase or Google Play Billing. See the [Billing FAQ](/docs/guides/billing/overview#does-clerk-billing-work-in-native-mobile-apps) for more information.
