### `updateCheckout()`

Applies or removes a promo code on an existing Billing checkout for the current user or supplied Organization.

Returns a [`BillingCheckoutResource`](/docs/reference/types/billing-checkout-resource) object.

```typescript
function updateCheckout(params: UpdateCheckoutParams): Promise<BillingCheckoutResource>
```

#### `UpdateCheckoutParams`


| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="id"></a> `id` | `string` | The unique identifier for the checkout session. |
| <a id="orgid"></a> `orgId?` | `string` | The Organization ID to perform the request on. |
| <a id="promocode"></a> `promoCode` | `string` | The promo code to apply. Use an empty string to remove the applied promo code. |
