**[Client ID Metadata Documents (CIMD)](https://datatracker.ietf.org/doc/draft-ietf-oauth-client-id-metadata-document/)** let an OAuth client use an HTTPS URL as its `client_id`. The URL serves a JSON document that describes the client, including its name, logo, and allowed redirect URIs, so an authorization server can identify the client without a pre-issued client ID, client secret, or Dynamic Client Registration.
