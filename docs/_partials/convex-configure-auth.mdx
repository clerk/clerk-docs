## Configure Convex with Clerk's Frontend API URL

1. Convex backend functions don't read your app's `.env` file. In your Convex project, run the following command to set your Clerk [Frontend API URL](!frontend-api-url):

   ```sh {{ filename: 'terminal' }}
   npx convex env set CLERK_FRONTEND_API_URL <fapi_url>
   ```

   > [!NOTE]
   > This command needs an existing Convex deployment. If you don't have one yet, run `npx convex dev --once` to configure the project and create it, then rerun the command above.

1. In your Convex project's `convex` folder, create an `auth.config.ts` file with the following configuration:

   ```ts {{ filename: 'convex/auth.config.ts' }}
   import type { AuthConfig } from 'convex/server'

   export default {
     providers: [
       {
         domain: process.env.CLERK_FRONTEND_API_URL!,
         applicationID: 'convex',
       },
     ],
   } satisfies AuthConfig
   ```

## Sync your auth configuration

In your Convex project, run the following command to sync your auth configuration to your Convex backend:

```sh {{ filename: 'terminal' }}
npx convex dev
```
