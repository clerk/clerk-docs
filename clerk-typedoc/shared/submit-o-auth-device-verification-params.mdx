The parameters for approving or denying an OAuth device authorization.

## Properties

| Property                                      | Type      | Description                                                                                                                  |
| --------------------------------------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------- |
| <a id="approved"></a> `approved`              | `boolean` | Whether to approve or deny the authorization request.                                                                        |
| <a id="organizationid"></a> `organizationId?` | `string`  | The ID of the Organization to authorize the request for. Omit this to authorize the request for the user's personal account. |
| <a id="usercode"></a> `userCode`              | `string`  | The user code displayed by the device requesting authorization.                                                              |
