The browser lands on `destination`, or on the Home URL set in the Clerk Dashboard if the link isn't valid. The page usually loads signed out. For `other_user_signed_in` and `impersonation_in_progress`, Clerk leaves the browser's sessions as they were, so the page stays signed in as the other user or in the impersonation session. Either page gets the following query parameters:

- `__clerk_status` is `session_transfer_failed`.
- `__clerk_error_code` is the reason, such as `expired` or `other_user_signed_in`.
