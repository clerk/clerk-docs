An interface representing OAuth consent information, including application details and requested scopes.

## Properties

| Property                                                       | Type                                                                          | Description                                                                                                                                                                                                                        |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <a id="clientid"></a> `clientId`                               | `string`                                                                      | The OAuth `client_id` identifying the application.                                                                                                                                                                                 |
| <a id="clientmetadatahost"></a> `clientMetadataHost?`          | <code>null \| string</code>                                                   | The host that serves the client's Client ID Metadata Document. Null unless `clientRegistration` is `metadata_document`.                                                                                                            |
| <a id="clientregistration"></a> `clientRegistration?`          | <code>"preregistered" \| "dynamic" \| "metadata_document"</code>              | How the client's identity was established. Undefined when the backend does not report it.                                                                                                                                          |
| <a id="maxorganizations"></a> `maxOrganizations?`              | `number`                                                                      | The most organizations one consent can grant. `1` unless the instance allows a consent for several organizations. Undefined when the value is not reported; treat that as `1`.                                                     |
| <a id="oauthapplicationlogourl"></a> `oauthApplicationLogoUrl` | `string`                                                                      | The URL of the OAuth application's logo image.                                                                                                                                                                                     |
| <a id="oauthapplicationname"></a> `oauthApplicationName`       | `string`                                                                      | The display name of the OAuth application requesting access.                                                                                                                                                                       |
| <a id="oauthapplicationurl"></a> `oauthApplicationUrl`         | `string`                                                                      | The homepage URL of the OAuth application.                                                                                                                                                                                         |
| <a id="redirectdomain"></a> `redirectDomain`                   | <code>null \| string</code>                                                   | The PSL-resolved registrable domain of the redirect URI for display on the consent screen. Null when no redirect URI was provided, when it is not registered for the application, or when it points to an IP address or localhost. |
| <a id="scopes"></a> `scopes`                                   | <code>[OAuthConsentScope](/docs/reference/types/oauth-consent-scope)[]</code> | A list of scopes the application is requesting, with descriptions and consent requirements.                                                                                                                                        |
| <a id="state"></a> `state`                                     | `string`                                                                      | The `state` parameter from the original authorize request.                                                                                                                                                                         |
