---
title: '`getClientList()`'
description: Retrieves the list of clients.
tag: deprecated
---

> [!DEPRECATED]
> This method is deprecated and will be removed in a future version. There is no direct replacement for listing all clients. To retrieve a specific client, use [`getClient()`](/docs/reference/backend/client/get-client) instead.

```tsx
const clients = await clerkClient.clients.getClientList()
```
