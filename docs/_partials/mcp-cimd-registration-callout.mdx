> [!IMPORTANT]
> Clerk supports both [Client ID Metadata Documents (CIMD)](/docs/guides/configure/auth-strategies/oauth/client-id-metadata-documents) and [Dynamic Client Registration](https://openid.net/specs/openid-connect-registration-1_0.html) for OAuth client registration. A CIMD-compatible client uses an HTTPS metadata URL as its client ID and doesn't need Dynamic Client Registration. CIMD is currently in beta — [contact support](/contact/support) to have it enabled for your account.
>
> In the Clerk Dashboard, navigate to the [**OAuth applications**](https://dashboard.clerk.com/~/oauth-applications) page and select the **Settings** tab. Under **Client onboarding**, enable **Publish CIMD support** to toggle CIMD support for your instance.
>
> Enable **Publish DCR support** only if the client doesn't support CIMD and requires DCR.
>
> CIMD clients always require Proof Key for Code Exchange (PKCE) with the `S256` method.
