The `BillingCredits` type represents the credits applied to a checkout or payment.

## Properties

| Property                           | Type                                                                                                       | Description                                                                                              |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| <a id="payer"></a> `payer`         | <code>null \| [BillingPayerCredit](/docs/reference/types/billing-payer-credit)</code>                      | The payer credit applied to the transaction. `null` when no payer credit applies.                        |
| <a id="proration"></a> `proration` | <code>null \| [BillingProrationCreditDetail](/docs/reference/types/billing-proration-credit-detail)</code> | The credit for the unused portion of the current billing cycle. `null` when no proration credit applies. |
| <a id="total"></a> `total`         | [`BillingMoneyAmount`](/docs/reference/types/billing-money-amount)                                         | The total monetary value of all credits applied to the transaction.                                      |
