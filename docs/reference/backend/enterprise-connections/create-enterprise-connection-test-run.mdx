## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `POST/enterprise_connections/{enterprise_connection_id}/test_runs`. See the [BAPI reference](/docs/reference/backend-api/tag/enterprise-connections/POST/enterprise_connections/%7Benterprise_connection_id%7D/test_runs){{ target: '_blank' }} for more information.
