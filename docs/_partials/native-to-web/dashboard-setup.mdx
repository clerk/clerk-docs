> [!IMPORTANT]
> Native to Web SSO is free in development instances. In production, it requires the Pro or Business plan. See [pricing](/pricing).

1. In the Clerk Dashboard, navigate to the [**Native applications**](https://dashboard.clerk.com/~/native-applications) page.
1. Enable the Native API, if it isn't already.
1. Turn on **Native to Web SSO**. Until you do, Clerk can't create sign-in links and returns the `feature_not_enabled` error code.
