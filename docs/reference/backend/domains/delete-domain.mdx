> [!DEPRECATED]
> This method is deprecated. Use the [`delete()`](/docs/reference/backend/domains/delete) method instead.

Deletes a domain for the instance. You can't delete the active domain. Returns a [`DeletedObject`](/docs/reference/backend/types/deleted-object).

```ts
function deleteDomain(domainId: string): Promise<DeletedObject>
```

## Parameters

<Properties>
  - `domainId`
  - `string`

  The ID of the domain to delete.
</Properties>

## Usage

<Include src="_partials/backend/usage" />

```tsx
const response = await clerkClient.domains.deleteDomain('domain_123')
```
