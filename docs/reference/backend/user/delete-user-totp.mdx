---
title: '`deleteUserTOTP()`'
description: Use the deleteUserTOTP() method to delete all of a user's TOTPs.
---

<Typedoc src="backend/user-api/methods/delete-user-totp" />

> [!TIP]
> This method removes the user's authenticator app enrollment. If the user has no other second factor enrolled, Clerk also deletes their backup codes and disables MFA. To remove every MFA method at once, use [`disableUserMFA()`](/docs/reference/backend/user/disable-user-mfa). See [MFA account recovery](/docs/guides/secure/mfa-recovery).

## Usage

<Include src="_partials/backend/usage" />

```tsx
const userId = 'user_123'

const response = await clerkClient.users.deleteUserTOTP(userId)
```

## Backend API (BAPI) endpoint

This method in the SDK is a wrapper around the BAPI endpoint `DELETE/users/{user_id}/totp`. See the [BAPI reference](/docs/reference/backend-api/tag/users/DELETE/users/%7Buser_id%7D/totp){{ target: '_blank' }} for more information.
