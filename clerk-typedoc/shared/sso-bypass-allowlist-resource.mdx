## Properties

| Property                             | Type                                                                                                               | Description                                                                                                                                                                                    |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <a id="adduser"></a> `addUser`       | <code>(params: AddSSOBypassAllowlistUserParams) => Promise\<SSOBypassAllowlistUserResource\></code>                | Adds a member to the allowlist. The member must hold a verified email address served by one of the organization's enterprise connections.                                                      |
| <a id="addusers"></a> `addUsers`     | <code>(params: AddSSOBypassAllowlistUsersParams) => Promise\<SSOBypassAllowlistBulkCreateResult\></code>           | Adds several members to the allowlist, one request per 100 ids. Members who cannot be added are reported in `errors` with the same code `addUser` returns for them, and do not fail the batch. |
| <a id="getusers"></a> `getUsers`     | <code>() => Promise\<SSOBypassAllowlistUserResource[]\></code>                                                     | Lists the members who may sign in with an email code when the organization's enterprise SSO is unavailable. Requires the `org:sys_entconns_sso_bypass:manage` permission.                      |
| <a id="removeuser"></a> `removeUser` | <code>(userId: string) => Promise\<[DeletedObjectResource](/docs/reference/types/deleted-object-resource)\></code> | Removes a member from the allowlist.                                                                                                                                                           |
